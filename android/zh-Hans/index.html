Tripin

隐私政策

生效日期：2026年9月27日

Tripin 是一款可以帮助你按天规划旅行行程、记录旅行中支出，并在地图上查看的 Android 应用。 本政策说明应用中处理的信息以及你可以做出的选择。

完整的旅行、行程及支出记录都保存在你的设备上，Tripin 不提供注册账号或自有服务器同步功能。 你为支出或旅行添加的照片也仅保存在设备上。使用地图或地点搜索时，你请求的地图范围或 搜索内容可能会发送给外部服务。

1. 运营者与适用范围

本政策适用于由个人开发者提供的 Tripin Android 应用，以及本隐私政策页面。 Tripin 不运营账号系统或自有后端服务器。有关个人信息处理的咨询， 可通过本政策末尾的邮箱地址提交。

2. 处理的信息与使用目的

旅行、行程及支出记录

旅行名称、城市、期间、预算、货币、支出地点、类别、金额、日期、地址，以及支出所 保存地点的位置坐标，用于旅行管理、支出记录、预算与统计显示功能。当你添加旅行 行程时，行程名称、地点名称、类别、日期与时间、备注以及地点的位置坐标，用于 行程管理与地图显示功能。这些记录保存在你的设备上，不会传送到开发者的服务器。

照片

当你要为支出或旅行添加照片时，会通过 Android 的系统照片选择工具（照片选择器） 或相机应用导入照片。采用这种方式后，应用不会另外请求相册或相机权限，只有你 主动选择或拍摄的照片才会提供给应用。导入的照片保存在你设备上 Tripin 专用的 存储空间中，不会传送到开发者服务器或其他外部服务。

用相机拍摄的照片，在你确认拍摄的同时会保存到 Tripin，并同时保存到 Android 系统相册（Pictures/Tripin 文件夹）中。如果取消拍摄，则不会保存在任何地方。 从相册中选择的既有照片，不会重新保存或复制到系统相册中。在 Android 9 及以下 版本的设备上，应用可能会请求存储写入权限，以便将拍摄的照片保存到相册。

删除支出或旅行时，Tripin 专用存储空间中对应的照片副本也会一并删除。但用相机 拍摄并保存在系统相册中的原始照片不会被删除，如需删除，请直接在 Android 的 图库应用中操作。

位置信息

当你授予位置权限并使用当前位置功能或地点搜索时，应用会将你的当前位置用于 地图移动以及搜索附近地点。支出和行程在添加过程中都可以使用相同的地点搜索 功能。应用不会在后台追踪你的位置，也不会将设备的当前位置持续保存到开发者的 服务器上。即使不授予位置权限，你也可以手动输入旅行、行程和支出信息。

广告及广告相关信息

应用使用 Google Mobile Ads SDK 及 Google User Messaging Platform（UMP）来 展示广告并管理相关同意设置。出于投放广告、频次控制、防止欺诈、效果测量及 同意管理等目的，Google 可能会处理根据 IP 地址推断出的大致位置、设备标识符 （例如 Android 广告 ID 或应用/开发者范围标识符等）、广告展示信息、应用启动 与点击等产品互动数据，以及崩溃记录和性能、诊断信息等。

应用首先会通过 UMP 确认特定地区是否需要同意流程，并显示必要的同意界面。此 阶段不会请求任何广告。只有当 UMP 判断可以请求广告后，应用才会在每次 启动时初始化一次 Google Mobile Ads SDK 并请求广告。如果同意信息无法 刷新，可能会使用此前保存的有效同意状态。广告是否个性化取决于 UMP 记录的同意 信号以及 Google 的适用政策。

Apple 的 App 跟踪透明度（ATT）是 iOS 专有功能，Android 版本未实现该功能。在 Android 上，上述 UMP 同意流程承担相应作用，你可以在 Android 设置中重置或 删除广告 ID。删除广告 ID 并不会停止用于投放非个性化广告、频次控制、汇总报告 及防止欺诈所进行的全部处理。无论你的同意选择如何，旅行管理、地图及支出记录 等应用的核心功能都可以继续使用。

3. 不收集的信息

应用不提供注册功能，也不会要求提供姓名、密码、支付卡号或银行账户信息。应用内 也没有单独的咨询表单。如果你直接通过下方邮箱联系我们，邮件服务提供商可能会 处理你的邮箱地址及咨询内容。

4. 外部服务与信息传输

为提供应用功能与广告服务，我们使用以下外部服务。

  • Google 地图（Maps SDK for Android）及 Google Play 服务： 用于地图显示与获取设备位置。显示、移动或缩放地图时，Google 可能会处理正在 查看的地图范围等一般网络信息，以及 IP 地址、设备与 SDK 信息、Maps SDK 标识符和崩溃信息。 Google 隐私政策
  • Geoapify 地点搜索：用于搜索商店、住宿及景点。执行搜索时， 会发送搜索关键词、显示语言及 IP 地址；当前位置可用时，还会一并发送 四舍五入到小数点后三位的坐标作为搜索基准点。即使经过四舍 五入，坐标仍可能表示较精确的位置。如果无法获取当前位置，为提高搜索准确度， 当前所选旅行中保存的城市名称可能会被附加到搜索关键词中一并发送。搜索结果 可能会暂时保存在应用内存中；未作为旅行记录保存的搜索词，不会另外保存在 应用的永久存储空间中。Geoapify 的地点数据基于 OpenStreetMap 贡献者的数据。 Geoapify 隐私政策 · OpenStreetMap 隐私政策
  • Frankfurter 汇率 API：用于将以其他货币输入的支出换算为 旅行货币，并提供汇率计算器功能。请求中仅发送两个货币代码及基准 日期，不会发送支出金额或旅行、位置信息。过去的支出使用该支出发生 当日的汇率，今天及以后的支出与计算器则使用最新汇率。获取到的汇率会暂时 保存在应用内存中，不会另外保存在设备的永久存储空间中。 Frankfurter
  • Google Mobile Ads 及 Google User Messaging Platform：用于 提供广告与管理同意设置。有关 Google 信息处理方式的详细内容，可参阅 Google 隐私政策 以及 使用 Google 服务的应用中信息处理方式说明。
  • GitHub Pages：用于公开托管本隐私政策页面。当你打开本页面 时，GitHub 可能会依照其自身政策处理 IP 地址、浏览器及请求记录等一般访问 信息。 GitHub 隐私声明

上述服务提供商可能会在包括其服务运营所在国在内的境外服务器上处理信息。具体的 处理国家、保存期限、删除方式及处理方式，依各提供商的政策及你的同意选择而定。 开发者会确认各项服务的条款与隐私政策，以确保外部服务提供商依据相关合约、 适用法律及 Google Play 的要求，对信息提供适当程度的保护。

5. 保存与删除

旅行、行程及支出记录会保存在你的设备上，直到你在应用中删除为止。你可以在应用 中删除单条支出、单条行程、整个旅行，或通过设置中的删除所有旅行 数据一次性清除设备上保存的全部记录。卸载应用或在 Android 设置中清除 应用存储空间，也会删除设备上保存的应用数据。

如果 Android 备份功能已开启，旅行、行程、支出记录及应用设置可能会包含在 Google 账号备份或设备间数据迁移中，并在之后被恢复。这些备份的保存与删除 依据你的设备与账号备份设置以及 Google 的政策而定；在应用内删除记录不会立即 删除已经生成的备份或已导出的文件。

地点搜索服务与广告服务所处理信息的保存与删除，依各服务提供商的政策而定。有关 开发者可控信息的确认或删除请求，可通过下方联系方式提交。

6. 你的选择与权利

  • 你可以随时在 Android 设置的应用权限页面，或应用自身设置中的位置权限项变更位置权限。
  • 添加照片会通过系统照片选择器和相机应用完成，无需另外授权；在 Android 9 及以下版本上可能被请求的存储写入权限，可以在 Android 设置的应用权限页面中变更。
  • 你可以在 Android 设备的设置 > 隐私 > 广告中重置或删除广告 ID。
  • 如果所在地区提供相关功能，你可以在应用设置的隐私选择中重新确认或变更广告同意设置。
  • 你可以在应用中直接编辑或删除旅行、行程与支出记录。
  • 你可以通过设置中的导出数据功能，将设备上保存的旅行与支出记录导出为 CSV 文件。 导出的文件会传送到你选择的位置或应用，不会发送给开发者。
  • 你可以通过设置中的删除所有旅行数据一次性清除设备上保存的记录。
  • 如需查阅、更正或删除开发者所掌控的信息，或对个人信息处理有任何疑问，可通过下方联系方式提出。

7. 信息保护

旅行、行程及支出记录保存在 Android 应用专用存储区域内。应用与外部服务之间的 网络请求均使用 HTTPS。不过，任何存储或传输方式都无法保证绝对安全，设备的屏幕 锁定与备份设置也会影响信息的保护程度。开发者会尽力维持与应用功能及所处理 信息性质相匹配的合理保护措施。

8. 儿童隐私

Tripin 并非专为儿童设计的服务，也不会故意收集儿童的个人信息。如果你认为儿童的 个人信息被处理，请通过下方联系方式告知我们。

9. 政策变更

若应用功能、所使用的外部服务或相关法规发生变化，本政策可能会随之修订。重大 变更将通过本页面或应用进行说明，并更新生效日期。
