Tripin

隱私權政策

生效日期：2026年9月30日

Tripin 是一款可以幫助你按天規劃旅行行程、記錄旅行中支出，並在地圖上查看的 Android 應用程式。本政策說明應用程式中處理的資訊以及你可以做出的選擇。

完整的旅行、行程與支出記錄都保存在你的裝置上，Tripin 不提供註冊帳號或自有 伺服器同步功能。你為支出或旅行新增的照片也僅保存在裝置上。使用地圖或地點 搜尋時，你請求的地圖範圍或搜尋內容可能會傳送給外部服務。

1. 營運者與適用範圍

本政策適用於由個人開發者提供的 Tripin Android 應用程式，以及本隱私權政策 頁面。Tripin 不營運帳號系統或自有後端伺服器。有關個人資料處理的詢問， 可透過本政策末尾的電子郵件地址提出。

2. 處理的資訊與使用目的

旅行、行程及支出記錄

旅行名稱、城市、期間、預算、貨幣、支出地點、類別、金額、日期、地址，以及 支出所保存地點的位置座標，用於旅行管理、支出記錄、預算與統計顯示功能。 當你新增旅行行程時，行程名稱、地點名稱、類別、日期與時間、備註以及地點的 位置座標，用於行程管理與地圖顯示功能。這些記錄保存在你的裝置上，不會傳送 到開發者的伺服器。

照片

當你要為支出或旅行新增照片時，會透過 Android 的系統照片選擇工具（相片 選擇器）或相機應用程式匯入照片。採用這種方式後，應用程式不會另外要求相簿 或相機權限，只有你主動選取或拍攝的照片才會提供給應用程式。匯入的照片保存 在你裝置上 Tripin 專用的儲存空間中，不會傳送到開發者伺服器或其他外部服務。

用相機拍攝的照片，在你確認拍攝的同時會保存到 Tripin，並同時保存到 Android 系統相簿（Pictures/Tripin 資料夾）中。如果取消拍攝，則不會保存在任何地方。 從相簿中選取的既有照片，不會重新保存或複製到系統相簿中。在 Android 9 以下 版本的裝置上，應用程式可能會要求儲存空間寫入權限，以便將拍攝的照片保存到 相簿。

刪除支出或旅行時，Tripin 專用儲存空間中對應的照片副本也會一併刪除。但用 相機拍攝並保存在系統相簿中的原始照片不會被刪除，如需刪除，請直接在 Android 的圖庫應用程式中操作。

位置資訊

當你授予位置權限並使用目前位置功能或地點搜尋時，應用程式會將你的目前位置 用於地圖移動以及搜尋附近地點。支出和行程在新增過程中都可以使用相同的地點 搜尋功能。應用程式不會在背景追蹤你的位置，也不會將裝置的目前位置持續保存 到開發者的伺服器上。即使不授予位置權限，你也可以手動輸入旅行、行程與支出 資訊。

廣告及廣告相關資訊

應用程式使用 Google Mobile Ads SDK 及 Google User Messaging Platform （UMP）來顯示廣告並管理相關同意設定。基於投放廣告、頻次控制、防止詐騙、 成效衡量及同意管理等目的，Google 可能會處理根據 IP 位址推斷出的大致位置、 裝置識別碼（例如 Android 廣告 ID 或應用程式／開發者範圍識別碼等）、廣告 曝光資訊、應用程式啟動與點擊等產品互動資料，以及當機記錄和效能、診斷 資訊等。

應用程式會先透過 UMP 確認特定地區是否需要同意流程，並顯示必要的同意畫面。 此階段不會請求任何廣告。只有當 UMP 判斷可以請求廣告後，應用程式才會 在每次啟動時初始化一次 Google Mobile Ads SDK 並請求廣告。 如果同意資訊無法重新整理，可能會使用先前保存的有效同意狀態。廣告是否個人 化取決於 UMP 記錄的同意訊號以及 Google 的適用政策。

Apple 的 App 追蹤透明度（ATT）是 iOS 專屬功能，Android 版本並未實作此 功能。在 Android 上，上述 UMP 同意流程扮演相應角色，你可以在 Android 設定 中重設或刪除廣告 ID。刪除廣告 ID 並不會停止用於投放非個人化廣告、頻次 控制、彙總報告及防止詐騙所進行的全部處理。無論你的同意選擇為何，旅行管理、 地圖及支出記錄等應用程式的核心功能都可以繼續使用。

3. 不蒐集的資訊

應用程式不提供註冊功能，也不會要求提供姓名、密碼、支付卡號或銀行帳戶 資訊。應用程式內也沒有單獨的詢問表單。如果你直接透過下方電子郵件聯絡我們， 郵件服務提供商可能會處理你的電子郵件地址及詢問內容。

4. 外部服務與資訊傳輸

為提供應用程式功能與廣告服務，我們使用以下外部服務。

  • Google 地圖（Maps SDK for Android）及 Google Play 服務： 用於地圖顯示與取得裝置位置。顯示、移動或縮放地圖時，Google 可能會處理 正在檢視的地圖範圍等一般網路資訊，以及 IP 位址、裝置與 SDK 資訊、Maps SDK 識別碼和當機資訊。 Google 隱私權政策
  • Geoapify 地點搜尋：用於搜尋商店、住宿及景點。執行搜尋 時，會傳送搜尋關鍵字、顯示語言及 IP 位址；當目前位置可用時，還會一併 傳送四捨五入至小數點後三位的座標作為搜尋基準點。即使 經過四捨五入，座標仍可能代表較精確的位置。如果無法取得目前位置，為 提高搜尋準確度，目前所選旅行中保存的城市名稱可能會被附加到搜尋關鍵字 中一併傳送。搜尋結果可能會暫時保存在應用程式記憶體中；未作為旅行記錄 保存的搜尋字詞，不會另外保存在應用程式的永久儲存空間中。Geoapify 的 地點資料基於 OpenStreetMap 貢獻者的資料。 Geoapify 隱私權政策 · OpenStreetMap 隱私權政策
  • Frankfurter 匯率 API：用於將以其他貨幣輸入的支出換算為 旅行貨幣，並提供匯率計算機功能。請求中僅傳送兩個貨幣代碼及 基準日期，不會傳送支出金額或旅行、位置資訊。過去的支出使用該 支出發生當日的匯率，今天及以後的支出與計算機則使用最新匯率。取得的 匯率會暫時保存在應用程式記憶體中，不會另外保存在裝置的永久儲存空間中。 Frankfurter
  • Google Mobile Ads 及 Google User Messaging Platform： 用於提供廣告與管理同意設定。有關 Google 資訊處理方式的詳細內容，可參閱 Google 隱私權政策 以及 使用 Google 服務的應用程式中資訊處理方式說明。
  • GitHub Pages：用於公開託管本隱私權政策頁面。當你開啟 本頁面時，GitHub 可能會依照其自身政策處理 IP 位址、瀏覽器及請求記錄 等一般存取資訊。 GitHub 隱私權聲明

上述服務提供商可能會在包括其服務營運所在國在內的境外伺服器上處理資訊。 具體的處理國家、保存期限、刪除方式及處理方式，依各提供商的政策及你的 同意選擇而定。開發者會確認各項服務的條款與隱私權政策，以確保外部服務 提供商依據相關合約、適用法律及 Google Play 的要求，對資訊提供適當程度的 保護。

5. 保存與刪除

旅行、行程及支出記錄會保存在你的裝置上，直到你在應用程式中刪除為止。你可以 在應用程式中刪除單筆支出、單筆行程、整個旅行，或透過設定中的刪除 所有旅行資料一次清除裝置上保存的全部記錄。解除安裝應用程式或在 Android 設定中清除應用程式儲存空間，也會刪除裝置上保存的應用程式資料。

如果 Android 備份功能已開啟，旅行、行程、支出記錄及應用程式設定可能會 包含在 Google 帳號備份或裝置間資料轉移中，並在之後被還原。這些備份的 保存與刪除依你的裝置與帳號備份設定以及 Google 的政策而定；在應用程式內 刪除記錄不會立即刪除已經產生的備份或已匯出的檔案。

地點搜尋服務與廣告服務所處理資訊的保存與刪除，依各服務提供商的政策而定。 有關開發者可控資訊的確認或刪除請求，可透過下方聯絡方式提出。

6. 你的選擇與權利

  • 你可以隨時在 Android 設定的應用程式權限頁面，或應用程式自身設定中的位置權限項目變更位置權限。
  • 新增照片會透過系統照片選擇工具與相機應用程式完成，不需要另外授權；在 Android 9 以下版本上可能被要求的儲存空間寫入權限，可以在 Android 設定的應用程式權限頁面中變更。
  • 你可以在 Android 裝置的設定 > 隱私權 > 廣告中重設或刪除廣告 ID。
  • 如果所在地區提供相關功能，你可以在應用程式設定的隱私權選擇中重新確認或變更廣告同意設定。
  • 你可以在應用程式中直接編輯或刪除旅行、行程與支出記錄。
  • 你可以透過設定中的匯出資料功能，將裝置上保存的旅行行程與支出記錄匯出為 Excel、PDF 或 CSV 檔案。檔案在裝置上產生，匯出的檔案只會傳送到你選擇的位置或應用程式，不會傳送給開發者。
  • 你可以透過設定中的刪除所有旅行資料一次清除裝置上保存的記錄。
  • 如需查閱、更正或刪除開發者所掌控的資訊，或對個人資料處理有任何疑問，可透過下方聯絡方式提出。

7. 資訊保護

旅行、行程及支出記錄保存在 Android 應用程式專用儲存區域內。應用程式與 外部服務之間的網路請求均使用 HTTPS。不過，任何儲存或傳輸方式都無法保證 絕對安全，裝置的螢幕鎖定與備份設定也會影響資訊的保護程度。開發者會盡力 維持與應用程式功能及所處理資訊性質相符的合理保護措施。

8. 兒童隱私

Tripin 並非專為兒童設計的服務，也不會故意蒐集兒童的個人資料。如果你認為 兒童的個人資料遭到處理，請透過下方聯絡方式告知我們。

9. 政策變更

若應用程式功能、所使用的外部服務或相關法規發生變化，本政策可能會隨之 修訂。重大變更將透過本頁面或應用程式進行說明，並更新生效日期。
